# Where the skins in skins-render.jsonl come from.
#
# Two sources, taken together: the repositories the weewx wiki's own
# index names, and what GitHub returns for the weewx topics and for
# "weewx skin". The index lists what somebody announced and is not
# complete; the search finds the rest and returns a great deal that is
# not a skin at all. Which is which is decided by looking for a
# skin.conf, not by the list.
#
# To fetch and harvest them again:
#
#   python -m ct4.corpus fetch-skins --out /tmp/skins
#   python -m ct4.corpus harvest-skin-sources /tmp/skins
#
# A repository that has gone away is reported and passed over. Two of
# them had by 01-Sep-2026.
